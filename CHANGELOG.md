# BitsjUI 1.1.0

## New
- Unit frames fit around Blizzard's Cooldown Manager: the player frame sits to the left of the Essential row and the target frame to the right, both centred on it. When the row grows or shrinks, the frames move with it. Pet and target of target follow, along with the class resource bar, spell timers and target castbar. Turn it on or off and set the gap in /bui > Unit frames > Cooldown Manager.

## Fixed
- Character window: the stats list no longer runs past the bottom of the window. It scrolls with the mouse wheel, with a thin bar on the right when there is more to see.
